@if (aberto === 'empenho') {

Reserva formal do dinheiro no orçamento para garantir que haverá recurso para pagar uma despesa específica.

Fracionamento: Múltiplos empenhos pequenos para o mesmo fornecedor para evitar licitação.

Empenho "Fantasma": Reservas altas para empresas recém-criadas ou sem histórico.

Objeto incompatível: Empresa contratada para serviço estranho ao seu CNAE (atividade econômica).

Empenho Genérico: Descrições vagas (ex: "diversos") para ocultar o objeto real.

}
@if (aberto === 'liquidacao') {

Momento em que o governo confirma oficialmente que o produto ou serviço foi entregue.

Tempo Impossível: Liquidação realizada minutos ou poucas horas após a emissão do empenho.

Atestado Duvidoso: Liquidação de serviços contínuos sem medição periódica comprovada.

Divergência de Objeto: O que foi liquidado não corresponde ao item descrito no edital ou empenho.

}
@if (aberto === 'notas') {

Documento que detalha o objeto, a quantidade e o preço unitário de cada item entregue para justificar o valor pago.

Sobrepreço: Valores unitários acima da média de mercado para itens comuns.

Itens "Invisíveis": Quantidades físicas impossíveis de serem entregues no prazo (ex: toneladas de cimento em um dia).

Notas Sequenciais: Lotes de notas fiscais emitidos na mesma data ou sequência para o mesmo órgão.

Descrição Genérica: Notas com descrição insuficiente, impedindo a verificação do que foi entregue.

}
@if (aberto === 'pagamento') {

Transferência efetiva do dinheiro público para a conta bancária do fornecedor.

Sazonalidade Suspeita: Concentração atípica de pagamentos no final do ano ou vésperas de eleição.

Pagamento Antecipado: Pagamento feito antes da entrega efetiva (salvo casos previstos em lei).

Transferência em Lotes: Pagamentos massivos para um único fornecedor em um curto intervalo.

}
