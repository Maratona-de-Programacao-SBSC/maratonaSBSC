Glossário cidadão

Entenda o que cada etapa revela.

Conhecer o significado dos registros ajuda a fazer perguntas melhores e evita interpretações precipitadas.

@if (aberto() === 'empenho') {

É a reserva formal do orçamento para garantir recursos para uma despesa específica.

  • Observe descrições excessivamente genéricas.
  • Compare o objeto contratado com a atividade do fornecedor.
  • Procure fracionamentos recorrentes para o mesmo objeto.
}

@if (aberto() === 'liquidacao') {

É o reconhecimento oficial de que o produto ou serviço foi entregue conforme o combinado.

  • Verifique intervalos incompatíveis com o prazo de entrega.
  • Compare o objeto liquidado com o empenho.
  • Busque evidências de medição em serviços contínuos.
}

@if (aberto() === 'notas') {

É o documento que detalha itens, quantidades e preços usados para justificar o valor cobrado.

  • Compare preços unitários com referências conhecidas.
  • Observe quantidades incompatíveis com o prazo.
  • Questione descrições que não permitem identificar o item.
}

@if (aberto() === 'pagamento') {

É a transferência efetiva do recurso público para o fornecedor após as etapas anteriores.

  • Observe concentrações atípicas em períodos curtos.
  • Confira se o pagamento ocorreu após a entrega.
  • Compare o valor pago com o liquidado.
}
